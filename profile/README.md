### Claude Code Plugin (Beta)

Bill for the work you ship with Claude Code. The plugin records each session against the right client and Plan item: your time, agent time, compute and the commits that shipped. Confirm it in Review, then bill by your time or by delivered effort.

```bash
claude plugin marketplace add per-hr/claude-code-plugin
claude plugin install perhr@perhr --scope project
```

Then start work on an item with `/perhr:start PAY-214` and finish with `/perhr:done`. Your prompts and code stay on your computer.
